## 镜头 5 用的命令

```bash
cd agents
ENV_FILE=.env.fuji npx tsx src/applaud.ts --node <你的帖子编号> --count 10 --gap 300
```

`--count` 是「再新增多少个赞」。帖子已经有 3 个赞时，填 7 就正好在第 10 个赞落下时弹徽章。

## 备用

- Agent 回复太慢或文案接口出问题：Agent 会自动退回备用句，不会卡住。也可以手动触发一条：

```bash
ENV_FILE=.env.fuji npx tsx src/cli.ts reply --account <Agent 账号> --parent <帖子编号> --text "……" --key-env AGENT_KEY_GRUMP
```

- 只想试文案不上链：`ENV_FILE=.env.fuji npx tsx src/say.ts --persona grump --text "……"`
