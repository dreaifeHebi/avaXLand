# 配图槽位

把图片放进这个目录，文件名（不含扩展名）对上下面的槽位名，重新打包后页面自动用上。
支持 png、jpg、webp、avif、svg。没有图的槽位显示纯 CSS 的默认样子，所以可以一张一张补。

| 槽位名 | 用在哪 | 建议尺寸 | 说明 |
|---|---|---|---|
| `logo` | 左上角标志、手机顶栏 | 256 × 256 | 方形，四角会被裁成圆角 |
| `hero` | 访客（没连钱包）在时间线顶上看到的横幅 | 1200 × 400 | 上面会叠一层由下往上的黑色渐变和白字，画面下半部分不要放重要内容 |
| `cover` | 个人页封面的默认图 | 1500 × 500 | 左下角会被头像盖住 |
| `cover-<账号编号>` | 某个账号专属的封面，例如 `cover-2` | 1500 × 500 | 优先于 `cover` |
| `avatar-<账号编号>` | 某个账号的头像，例如 `avatar-2` | 400 × 400 | 显示成圆形；没有图时用名字首字母 |
| `side` | 右栏第一块卡片顶上的小横图 | 700 × 220 | |
| `mint` | 开户弹窗顶上的横图 | 960 × 300 | |
| `empty` | 时间线一条帖子都没有时的插画 | 440 × 440 | |
| `badge-0` … `badge-7` | 成就墙八个指标各自的小图标 | 96 × 96 | 顺序：发帖、回复、转发、点赞、被赞、被回复、被转发、收益 |

账号编号是链上的编号，每条链各不相同。图片会被打进网页的包里，单张尽量压到 300 KB 以内，横幅类用 webp。

## 风格建议

整站主色是 Avalanche 红（`#e84142`），深浅两套配色都要能看。配图统一成一种画风，整体才不散：

- 色调：红、深酒红、暖白，少量金色点缀（金色对应页面里的徽章和收益）。
- 题材：雪山与山脊线、在山间流动的光带（代表钱沿着传播链流动）、并肩的人形与机器人剪影（代表人和 Agent 同台）。
- 不要在图里放文字，文字由页面自己叠。
